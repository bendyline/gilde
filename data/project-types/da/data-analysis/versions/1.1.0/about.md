# Data Analysis

This project explores the datasets in its workspace. Its dashboard discovers
spreadsheets, delimited tables, structured data, and database files in the
project folder and its subfolders. Open a file to use Gezel's existing viewer.

Start with the question the person wants to answer. Inspect the relevant data,
explain missing values and assumptions, and support conclusions with evidence.
Keep original datasets intact; save derived data and reports as separate files.

The dashboard lists files and metadata, and uses Gezel's shared table APIs to
show row counts, numeric summaries, column types, and charts for indexed tables.
Charts start with record counts and offer explicit numeric averages. These are
descriptive summaries of the indexed snapshot, not conclusions about causality.
Unindexed files remain browsable; missing query support is explained on the page.
Hidden folders, document companion
folders, and dependency folders are omitted. Large or partly unreadable folders
are explicitly labeled as incomplete.

The shared Add files control imports selected datasets and reports into the workspace when managed writes are enabled, preserving existing files. New files appear before background table indexing may be ready. Standalone demo additions stay in memory; charts remain explicitly labeled sample data.
