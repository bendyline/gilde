# Media Library

This project is a window into a folder of photos, illustrations, videos, and
recordings. The gallery finds media in the workspace and its subfolders, with
search, folder and format filters, sorting, and a larger preview. Files stay
where they are: no import, copy, or reorganization is needed.

Help the person find and understand their collection. Preserve original media
and folder names. Discuss proposed edits or organization before changing files.
Do not assume a filename or modification date proves when or where a photo was
taken. Playback depends on the device's supported formats; unpreviewable files
remain listed and can be opened through Gezel's existing viewers.

The page only reads files. Hidden folders, dependency folders, and document
companion folders are skipped. Scans stop after 100 folders or 10,000 files and
clearly label a partial library. The bundled samples are only a standalone demo;
they are never inserted into a real project's folder.
